## Hygiene findings (task H10)

`U_CAN_Design/` holds **117 files, 18.5 MB**, of which 115 are unique.

**Filename normalisation.** 116 of 117 filenames needed changing for web use —
spaces, mixed case, underscores, and German umlauts (`LHD Förderlogo DEU auf
Farbe/Foerderlogo LHD auf Farbe.svg`). The staged tree is fully kebab-cased.

**Duplicates — 2 groups, ~0.1 MB recoverable:**

| bytes | duplicate pair |
|---|---|
| 61 KB | `Logos/EU Emblem and Cities Mission banner/EN_FundedbytheEU_RGB_POS.png` = `Logos/EU logos/EN_horizontal/RGB/PNG/EN_FundedbytheEU_RGB_POS.png` |
| 21 KB | `Logos/EU Emblem and Cities Mission banner/EN_fundedbyEU_VERTICAL_RGB_POS.png` = `Logos/EU logos/EN_vertical/RGB/PNG/EN_fundedbyEU_VERTICAL_RGB_POS.png` |

The `EU Emblem and Cities Mission banner/` copies are the redundant ones; the
`EU logos/` trees are the complete sets. Only the `EU logos/` copies were staged.

**The 2.7 MB font archive is 94% redundant.** `Bahnschrift-Font-Family.zip`
contains the same 315 KB file fifteen times (all md5 `b3483ec6…`). See
[`FONT-INVENTORY.md`](FONT-INVENTORY.md).

**What was deliberately not staged, and why:**

| left behind | reason |
|---|---|
| `Logos/EU logos/**/CMYK/**` (JPEG) | print colour space; JPEG is wrong for a logo on the web |
| `Logos/EU logos/**/EPS/**` | print vector; keep in source for the printer |
| `LHD/**/*.{ai,pdf,png}` | the SVG master of each of the 11 LHD variants was staged instead |
| `*.potx`, `*.docx`, `*.pptx` | Office sources — see task H11 below |
| `*.ai` | superseded by the extracted SVG masters |

**Asymmetry worth knowing:** the EN emblem set has a `Monochrome` RGB PNG and
the UA set does not; the UA set has a `Pantone` RGB PNG and the EN set does not
(EN Pantone exists only as CMYK JPEG). If a monochrome Ukrainian emblem is ever
needed it must be requested from the EU brand portal, not derived locally.

**Task H11 — the fate of `source/`.** Recommendation: **keep the four Office
binaries as provenance.** They are 5.2 MB combined, they are the only record of
where the tokens came from, and three tasks in this audit (B1, A1, A4) were
settled by reading them. Record them in `readme.md` as provenance-only, not as
live templates — the live templates are the Section E `.dc.html` files.
